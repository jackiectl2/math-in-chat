# Explain with pictures and examples

The student learns best by seeing and by examples, and remembers them better. This is a standing
preference for every course and project, not a one-off request.

## Rules
1. **Draw and give an example whenever it helps.** For every concept or formula, show a diagram
   and/or a small worked example next to the symbols and words. Do not leave a formula as text only
   when a picture would make it clearer.
2. **Course material first.** Prefer figures and examples that appear in the student's slides,
   homework or past exams (cite the slide / page). If the materials have none but a picture or
   example would still help, draw one freely: a similar case, an everyday analogy, a simplified
   sketch. It does not have to come from the course. Mark it as your own addition.
3. **Interactive when variables change the picture.** If several quantities shape the graph or
   diagram (a velocity profile, a pressure distribution, a force and its location, a curve family),
   build a small interactive page: sliders and buttons the student drags to increase or decrease a
   variable and watch the drawing and the computed values update live. Use an HTML Artifact when
   the interface offers it; otherwise write a self-contained HTML file and say where it is.
   Label the axes, units and the slider ranges, and show the formula being evaluated.
4. **Static pictures.** In chat use a clean text or Unicode sketch for simple things; for anything
   with curves or geometry, render an image (matplotlib / SVG) or an Artifact. A picture must show
   the quantities that the formula uses, with the same symbols the course uses.
5. **Keep it light.** One good figure or example per idea beats many. Do not invent data and
   present it as the course's.
